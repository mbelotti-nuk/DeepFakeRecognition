# Vision transformer application
 I created this repository to see how vision transformer works. Answer: they are really the same as transformer for language applications :p <br>

 SO, i made an application to detection of deep fake images available at https://www.kaggle.com/datasets/birdy654/cifake-real-and-ai-generated-synthetic-images/data <br>

It works quite well and got 91% accuracy on test set. I didn't spent too much time on refining accuracy or recall or whatever, it was just for fun
